<h3 align="center">nucloc</h3>

<p align="center"><i>fast, pretty loc counting</i></p>

--- 

`nucloc` is a little program for counting lines of code. Unlike many new Rust CLIs, it does not aim to be faster than the classic [cloc](https://github.com/AlDanial/cloc). Rather, it aims to be about as fast while being much nicer to use in a large number of ways.

```bash
cargo install nucloc 
brew install nucloc
```
